**Ivan Moreno**

[https://ivanmoreno.art/portraits](https://ivanmoreno.art/portraits)

Ivan present a book inspired by The Daily Stoic by Ryan Holiday and Stephen Hanselman, t. Each day, a thought from the book is brought to life, offering a space for quiet introspection through the fusion of philosophy and art.

Where each episode has a desciprtion on what are the good reasons for living. The digital web/book is enhanced with interacive images. Ivan created his own shader tool for those interactive visuals. Fot the design of the web book, each month utilizes a different color.

**Nuño**

[https://action-io.com](https://action-io.com)

Made an interactive installation that responds to the sounds in the forest for the Wilde Möhre festival in 2018, then expanded it and rewrote the entire control software in Processing. Brought it to the Creative Code Jam. On Saturday morning, shows custom Processing software that drives lights. Uses the latest Processing which runs in Snap, communicating in Serial over USB to a small Arduino board combined with a radio module that controls lasers through radio signal. (ultra low latency, about 3ms). No automated beat detection (just tap based).

**Hao**

[https://filebin.net/i8p83mznqkyix9u1](https://filebin.net/i8p83mznqkyix9u1)

Shows how simple movements can evolve to complicated patterns after differentiation.

Hao runs his own python code that displays 6 graph charts with the values of a 2D pendulum. Each charts represents the data on different dimentions on each axis like position, velocity or aceletarions vs time.

**Maiko**

Maiko presents Berlin Quest, a videogame from 2018-19 from when Meiko migrated to Berlin.

[https://meyco.itch.io/berlin-quest-alpha](https://meyco.itch.io/berlin-quest-alpha)

The retro RPG aesthetic game is a satire about real stories of her landing into the city.

Stories like language issues, flat hunting, Anmeldung, doctor's appointments or scammers.

Maiko has been working on a new game with longer story and less based on real stories and more fictional. (japanese only)

**Bernhard**

[https://www.instagram.com/bernh](https://www.instagram.com/bernhgardschmernhard/?hl=en)[g](https://www.instagram.com/bernhgardschmernhard/?hl=en)[ardschmernhard/?hl=en](https://www.instagram.com/bernhgardschmernhard/?hl=en)

Bernhard shows multiple of their works. From a custom typography face made on shaders that can adapt to any size, allowing extreme compositions with super wide and stretchy spaces. To a cap with shader code embordery.
